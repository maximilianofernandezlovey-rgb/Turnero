# Vault Obsidian — Turnero UADE

Esta carpeta es un Vault de Obsidian versionado dentro del repositorio del Turnero.

## Cómo abrirlo

1. Clonar o actualizar el repositorio `Turnero`.
2. Abrir Obsidian.
3. Elegir **Open folder as vault**.
4. Seleccionar la carpeta `docs/obsidian`.
5. Abrir `00 - Inicio/Inicio.md`.

## Qué se versiona

Se versionan las notas Markdown y la configuración mínima del Vault incluida en `.obsidian`.

No debe versionarse `workspace.json` ni configuraciones locales de ventanas/dispositivo.

## Fuente de verdad

- Obsidian: reglas funcionales, producto, UX/UI y decisiones.
- GitHub: código y versionado de esta documentación.
- Supabase: estado y reglas de datos implementadas.
- Vercel: despliegue de la aplicación.

Los cambios de producto deben documentarse primero en este Vault y luego implementarse en código.
