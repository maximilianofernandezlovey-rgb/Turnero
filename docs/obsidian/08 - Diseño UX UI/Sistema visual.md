# Sistema visual

## Dirección

Institucional, simple, contemporáneo y mobile-first. Evitar que la interfaz parezca un conjunto de componentes técnicos.

## Jerarquía

- Número de turno: elemento dominante en espera y llamado.
- Azul institucional: acciones y estados relevantes.
- Navy: identidad y contraste.
- Verde: confirmaciones reales, no decoración.
- Fondos claros y superficies blancas con bordes suaves.

## Principios

- Una pantalla = una tarea.
- Reducir pills, alerts y cajas simultáneas.
- No usar emojis como iconografía principal de estados críticos.
- Objetivos táctiles grandes en mobile.
- Texto secundario breve.
- La pantalla de llamado debe poder comprenderse en menos de un segundo.
- La interfaz del operador tendrá un sistema diferente: mayor densidad y foco operacional.
